# Security

If you discover a security vulnerability in this project, please open a private issue or contact the repository owner directly. Provide:
- A short summary of the issue
- Steps to reproduce (minimal repro if possible)
- Expected and actual behavior

Do NOT post sensitive data (keys, passwords, or access tokens) in public issues.

If you require a private channel, email: hassan200503@users.noreply.github.com (replace with your actual contact) or open a private support channel.
